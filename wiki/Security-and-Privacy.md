# セキュリティとプライバシー

P2P GPS は位置情報を扱うため、何を守り、何を守っていないかを明確にします。仕様の該当箇所は [`spec/protocol-v1.md`](https://github.com/haruki0420/p2pgps-protocol/blob/main/spec/protocol-v1.md) §8 です。

## 通信

- クラウドやアカウントを使いません。位置情報は BLE で端末間だけを流れます。
- v1 は BLE の認証・暗号化を行いません（ペアリング／ボンディングなし）。
- 近距離にいる第三者が、偽の位置を送り込める余地があります。v1 の前提として受け入れてください。

## 受信側の防御

- 位置の書き換えは既定 OFF です。ユーザーが画面で ON にしたときだけ動きます。
- 書き換え中は画面上部に常時バナー（送信元・最終受信時刻・座標）を表示します。
- 停止するとシミュレートした位置をクリアし、実位置に戻します。
- 自動接続は、ユーザーが許可した送信元（名前 + 識別子）だけを対象にします。

## ログ

- アプリの動作記録に座標を出さない方針です。
- 仕様 §8 は、ログに座標を残す場合の丸め（既定: 小数 5 桁 = 約 1 m）を定めています。

## pairing file

pairing file は iPad の RSD 接続に使う機密情報です。

- 共有・コミット・Issue への添付をしないでください。
- アプリは Application Support 配下に 0600 で保存し、Data Protection を設定します。
- 漏えいした可能性がある場合は、pairing file を作り直してください。

## 脆弱性の報告

脆弱性や個人情報の漏えいを見つけた場合は、公開 Issue に書かず [SECURITY.md](https://github.com/haruki0420/p2pgps/blob/main/SECURITY.md) の手順に従ってください。
