# カーナビ用途での適性

P2P GPS を車載ナビの位置ソースとして使えるかを整理します。

## 結論

- **カジュアルなナビ（現在地確認・ルートの目安）**: 実用範囲です。
- **車線案内・安全運転支援・自動運転**: 不適です。
- 推奨は **500 ms（2 Hz）+ Extended Location 有効**、両端末を給電し、Android の電池最適化を無効化することです。

## 遅延の目安

- GPS fix 1 Hz + BLE + 平滑化 + 位置シミュレーションで、体感 **0.5〜1.5 秒**。
- 時速 60 km/h では 1 秒で約 16.7 m 進むため、1 Hz だと **8〜25 m** の遅れが見込まれます。
- 2 Hz にすると遅れは半分程度になります。

## 精度

- スマートフォン GPS は **±5〜20 m**。車線レベルではありません。
- トンネル・高架下・都市部では誤差・欠測が増えます。
- 死測（ジャイロ・車速パルス）は行いません。

## 推奨設定

| 項目 | 推奨 |
| :--- | :--- |
| 送信間隔 | 500 ms（2 Hz） |
| Extended Location | ON |
| 位置情報を反映 | ON |
| Android の電池最適化 | P2P GPS を対象外 |
| 両端末の給電 | 必須 |
| 他の VPN | 切断 |
| iPad の画面 | ON のまま |

## 実機確認の観点

1. ナビアプリで現在地が動くか
2. 交差点を曲がったときの追従遅れ（1 Hz / 2 Hz）
3. トンネル・高架下で止まらないか
4. 10〜15 分走行して Android の通知が消えないか
5. iPad が熱で画面を暗くしないか

## 既知の制約

- iOS の位置シミュレーションは非公開サービス依存で、OS アップデートで壊れる可能性があります。
- BLE は 1 対 1。同じ車内に置いてください。
- pairing file / DDI / LocalDevVPN のセットアップが必要です。
- 安全運転支援・自動運転を目的とした認証製品ではありません。運転中の操作は同乗者が行ってください。

詳細は [`docs/car-navigation.md`](../docs/car-navigation.md) を参照してください。
